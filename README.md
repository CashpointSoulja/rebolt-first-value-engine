## Proposed scope — not implemented

Validated **synthetic** signup/event CSVs; honest cohort denominators; first-value milestones; segmentation; explainable experiment priority; UTM construction; activation-plan export. Definitions and implementation scope await product-use context. No claims about missing Rebolt features are made.

Later deliverables, subject to scope approval: full PM documentation, implementation with tests and recorded results, a free Cloudflare deployment, and a voiced walkthrough of the real running browser application. None is represented as complete at this stage.

## Verify the research bundle

```sh
python3 scripts/validate_research.py
```
