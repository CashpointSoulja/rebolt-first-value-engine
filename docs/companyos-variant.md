## Generic product descriptions — official claims

[Introducing Rebolt](https://www.rebolt.ai/introducing-rebolt) describes “The software platform for AI-powered operations,” aimed at operations leaders coordinating processes across systems and IT teams governing permissions, access and auditability. It describes Holocron as an operating model, Software Factory as a generator, and execution across events, approvals, exceptions and write-backs.

[Pitch Rebolt](https://www.rebolt.ai/pitch-rebolt) describes a “governed operational software layer.” Its pilot setup guidance is to choose an operation, map triggers/systems/rules/approvals/write-backs and define an operational improvement metric.

These descriptions are not independently verified product behavior. Editorial canonical metadata points to another hosting domain in these captures; citations intentionally use the official Rebolt domain. No alternate hosted product was consulted.

## Concept boundary

The proposed generic workbench would still analyze **GTM first value**, not execute business operations, clone Holocron or generate operational applications. Generic editorial copy does not establish the current signup journey, event taxonomy, pricing or feature gaps. Scope remains pending product-use notes.
